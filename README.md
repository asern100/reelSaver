# ReelSaver

تطبيق أندرويد يحمّل ريلز وفيديوهات تيك توك وانستغرام وفايسبوك ويوتيوب (فيديو ولا صوت MP3) بأعلى جودة متاحة (محرك yt-dlp + ffmpeg داخل التطبيق).

## باش تخرج الـ APK (بلاش Android Studio)
1. اعمل repo جديد في GitHub وارفع فيه محتوى هذا الملف (Add file ← Upload files).
2. ادخل لـ **Actions** ← يبدا البناء وحدو (حوالي 5 دقايق).
3. كيف يكمل، حل الـ run وهبّط **ReelSaver-apk** ← فيه:
   - `app-arm64-v8a-debug.apk` ← لأغلب التلفونات
   - `app-armeabi-v7a-debug.apk` ← للتلفونات القديمة

## الاستعمال
- من تيك توك/انستغرام/فيسبوك: **مشاركة ← ReelSaver** والتحميل يبدا وحدو.
- ولا انسخ الرابط ← «لصق من الحافظة» ← «تحميل».
- الفيديوات تتحط في `Download/ReelSaver`.
- كان التحميل وقف يخدم: «تحديث محرك التحميل».

ملاحظة: الريلز الخاصة (private) أو اللي تطلب تسجيل دخول ما تتحمّلش.
